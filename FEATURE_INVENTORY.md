# Feature Inventory: Mafia: Shadows of the City

This inventory catalogs every functional and visual feature of the application, categorized into:
1. **Original Pre-Existing Features**
2. **New Features Added (from Implementation & Audit Spec)**

For every entry, the trigger mechanism, expected behavior, automated verification test, and manual browser check procedure are documented.
